Database & Persistence Guide

Instructions for local testing, live persistent deployment, and admin lockdown.

1. Out-Of-The-Box Persistence

This web application uses browser LocalStorage synchronization by default so all public submissions, record edits, and status changes remain saved instantly across web browser reloads.

2. Connecting Live Cloud Firestore

To connect your own live Cloud Firestore database:

  1. Create a Firebase Project at console.firebase.google.com
  2. Enable Cloud Firestore and Firebase Authentication (Email/Password)
  3. Replace the `firebaseConfig` object in this page script with your project credentials

3. Recommended Firestore Security Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/registrations/{document=**} {
      allow create: if true; // Public registration submission
      allow read, update, delete: if request.auth != null && request.auth.token.email == 'admin@robotics.com';
    }
  }
}
